# 🤖 Gemini AI Chatbot

A simple and interactive AI chatbot built using **Python, Streamlit, and Google's Gemini API**.  
The application allows users to enter prompts and receive AI-generated responses through a clean and user-friendly web interface.

---

## ✨ Features

- 🤖 AI-powered chatbot using Google Gemini
- 💬 Interactive prompt input
- ⚡ Real-time AI-generated responses
- 🎨 Clean and simple Streamlit interface
- 🔐 Secure API key management using `.env`
- 🐍 Built completely with Python
- 🌐 Runs locally in a web browser

---

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Google Gemini API**
- **python-dotenv**
- **Git & GitHub**
